# 🏪 Supermarket POS - Quick Start Guide

## FOR WINDOWS USERS

### Installation Steps:

1. **Extract the ZIP file** to any location (Desktop is recommended)
   - Right-click the ZIP file
   - Click "Extract All..."
   - Choose a location

2. **Run the Application**
   - Open the extracted folder
   - Find and double-click: `Supermarket POS.exe`
   - That's it!

### First Time Setup:

When you open the application for the FIRST time:

1. You will see a **Setup Screen**
2. Enter YOUR information:
   - Your Full Name
   - Choose a Username
   - Create a Strong Password (minimum 6 characters, must have letters and numbers)
   - Confirm your password

3. Click **"Complete Setup"**

4. Done! The application will restart and you can login with YOUR credentials

### Daily Use:

- **Username:** The one YOU created during setup
- **Password:** The one YOU created during setup

### Important Notes:

✅ **Your data stays on YOUR computer** - All sales, products, and settings are saved locally

✅ **No internet required** - Works completely offline

✅ **Each computer needs its own setup** - If you install on multiple computers, each will have its own data unless you copy the database file

### Troubleshooting:

**Problem:** Application won't start
**Solution:** Make sure you extracted ALL files from the ZIP

**Problem:** Forgot password
**Solution:** Delete the file `pos_database.db` in the application folder and restart (WARNING: This deletes all your data!)
